# Review Rules

## Mandatory Questions
1. Is this XiaoNa?
2. Is this XiaoNa under the frozen body constitution?
3. Does this image teach one clear thing?
4. Does it belong to the current layer?
5. Will it pollute training?

## PASS
- is XiaoNa
- fits frozen body constitution
- layer responsibility is clear
- no major pollution signal

## WARN
- partially correct but unstable
- backup or observation only
- does not enter main training set

## FAIL
- not XiaoNa
- constitution mismatch
- proportion or limb collapse
- strong pose pollution
- dressed state changes the person

## Arbitration Rule
- final decision = algorithm score + human semantic review + group balance
