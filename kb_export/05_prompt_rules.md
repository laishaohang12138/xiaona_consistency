# Prompt Rules

## Formula
- Final prompt = Universal Base + Shot Plugin + Universal Negative

## Universal Base
- owns identity, body constitution, scene, lighting, clothing discipline, camera discipline, anatomy safety
- reusable across batches

## Shot Plugin
- owns only the local variable of one shot or one batch
- minimal change only
- cannot overthrow the base

## Universal Negative
- owns global failure interception:
  - identity drift
  - influencer face
  - hip pop
  - broken feet
  - dirty knees
  - erotic drift
  - background or lens pollution

## Scope Warning
- the imported master prompt is BODY GOLD only
- it is not the whole-project master prompt
